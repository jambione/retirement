Every file is fingerprinted by content before it is read, so the same export arriving twice — re-dropped, re-sent, or in a synced folder — makes one snapshot, not two. A duplicated month would show as a flat month that never happened.

Why an export rather than a live feed: eMoney's API is licensed to advisory firms and authenticated with a certificate the firm registers — there is no individual-client tier, so the key would have to come from your advisor. The numbers stay in the local database on this machine; nothing is sent anywhere unless you ask B a question.
